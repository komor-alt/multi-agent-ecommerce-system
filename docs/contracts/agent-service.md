# Python Agent Service Contract

These endpoints are internal. Business IDs are generated by NestJS.

## Create Agent Run

```text
POST /internal/agent-runs
```

Request:

```json
{
  "run_id": "uuid-from-nestjs",
  "task_type": "product_recommendation",
  "user_id": "user-id",
  "input": {},
  "agent_config": {
    "model": "deepseek-v4-flash",
    "max_steps": 8,
    "temperature": 0.3,
    "max_tokens": 1024,
    "rag_top_k": 5,
    "tool_whitelist": ["get_user_profile", "search_products", "check_inventory", "generate_copy"]
  }
}
```

Response:

```json
{
  "run_id": "uuid-from-nestjs",
  "status": "completed",
  "final_answer": {},
  "events": [],
  "metrics": {
    "latency_ms": 1200,
    "input_tokens": 1000,
    "output_tokens": 300,
    "total_tokens": 1300,
    "tool_call_count": 4
  },
  "error": null
}
```

## Responsibility Split

NestJS owns task creation, permissions, persistence, audit logs and frontend SSE.
Python owns model inference, workflow execution, tool execution and evaluation logic.
